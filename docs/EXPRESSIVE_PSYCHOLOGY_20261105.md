# 玩闹者危险感知与十四人展示重构（2026-11-05）

本次按用户要求更新已有双人玩闹入口及十四人入口。实际人机净距仅记录，不作为演示停止或模型通过条件。这里的“更真实”落实为可解释的刺激—心理—行为因果关系；新参数没有真实儿童数据支持，不能称为已辨识的儿童模型。

## 玩闹者怎样进入 SCARED

新开关 `playful_motion_fear` 默认关闭，只在本次两个演示配置的13/14号开启，普通人和旧模型配置保持原规则。

玩闹者把原几何风险 R 分为两部分：

- 静止或低速的近距离机器人：恐惧刺激风险为 `0.05 * R`，不再仅因自己接近机器人而触发紧急恐惧。
- 机器人主动朝人运动，径向速度至少0.35m/s，且相对速度预测会进入人体/机器人圆形包络加0.10m预测裕量：按预计首次包络交叉时间 TTC 计算紧迫性。TTC从3秒缩短到1.5秒，紧迫性从0升至1。
- 最终恐惧风险取两者较大者。机器人高速远离、从旁经过但轨迹不相交，或行人自己走向静止机器人，不满足“机器人迎面冲来”的条件。

这仍更新原恐惧 SIS 方程，继续接受人群恐惧传播。好奇的直接刺激、传播系数和好奇行为阈值不改；其几何输入仍采用原 R，避免修改恐惧通道时顺带放大好奇。

13/14号的累计恐惧进入阈值由0.65提高到0.80；已知紧迫威胁达到原紧急风险0.85时仍立即 SCARED，不等待恐惧量积累到0.80。危险判断考虑所有个人可见/有效记忆中的机器人，不局限于偏好对象，不从心理传播获得机器人位置。

在当前孤立个体的 `alpha_F=1, mu_F=0.25` 下，持续最大直接刺激使恐惧量渐近0.8；因此玩闹者的0.8累计阈值主要供社会传播叠加使用，单人突然危险由预测紧迫度触发紧急SCARED。该结构是本版明确的工程假设，后续数据拟合时需共同检查。

预测碰撞必须使用位置、运动方向、速度和身体尺寸；这与“不设最小实际净距验收线”不矛盾。预测裕量不约束实际轨迹，也不缩小人体包络。所有时间、速度、风险缩放仍为待标定工程初值。

占位上限由8秒调为10秒，原拦截、冷却、次数限制、任务暂停/回归保持。危险可以提前结束玩闹，不会为了凑足10秒压制恐惧；身体动作仍由社会力核心积分。恐惧退让目标净距采用2.0m，仅决定退让意图，不是实际最小净距保证。

```mermaid
flowchart LR
  A[慢速近距互动] --> B[较弱恐惧刺激 / 原好奇通道]
  B --> C[惊讶观察 → 好奇 → 条件性玩闹占位]
  D[机器人迎面运动且预测轨迹相交] --> E[TTC紧迫性]
  E --> F[恐惧SIS / 紧急避让]
  F --> G[SCARED并中止玩闹]
  G --> H[威胁减弱、心理恢复、继续原任务]
  C --> H
```

## 六类展示与数据编号

可视化展示六类：REGULAR、IMPASSIVE（心理不响应）、SURPRISED、CURIOUS、SCARED、THREATENING。IMPASSIVE同时注明 `immune_dynamic` 或 `impassive_static`，其数据层瞬时模式仍为REGULAR；另外五种仍用原模式编号。警戒是叠加标志，不伪造第六个瞬时模式，不修改旧 `Agent.behavior.type`。

继续使用现有角色资源。playful是明确配置的互动类型，不从角色外观推断年龄；本次没有加入儿童身体模型或独立头部注视。

## 十四人自动序列

十四人构成仍为8普通、2动态免疫、2静态障碍响应、2玩闹者。新增独立人群配置 `multi_14_psychology_expressive.yaml`、心理配置 `sis_cf_v2_expressive.yaml`，旧十四人基础配置与原任务文件留存。

入口文件名称按用户要求不变，但其中两台机器人已改为 `external`，不会启动DWB控制器；`auto_demo:=true` 启动新的 `crowd_stimulus` 节点。

首轮候选顺序：先静候8秒；robot_1低速通过13号区域；随后robot_2慢行与14号互动，robot_1低速接近普通人；两机短时朝指定行人加速，再停车、撤离；最后经过免疫/静态行人区域并观察恢复。最终时序以 `config/tasks/psychology_v2_expressive_sequence.yaml` 和验证报告为准。

脚本只读角色实际位置与机器人里程计，输出速度。它不读取心理值、行为模式、行人任务队列或Nav2规划，不设置行人模式。所有进入、未进入、提前终止都是模型计算结果。刺激序列按仿真时间推进，暂停不累计，时钟回退/观测或健康失效会停车并记录失败；没有人机净距中止条件。

## 有限注意假设与失败迭代

原身体朝向FOV会在行人转身避让时立即失去直接刺激。新增 `threat_attention_s` 默认0；本次展示设为4秒。
只有已在身体视野中、且正在惊讶/好奇/玩闹/恐惧互动的目标才能建立注意期限；离开身体视野后不续期，
超过期限或视距后停止当前观察。不能发现身后的陌生机器人；期限与心理事务一起提交。
日志将此知识来源记为 `tracked_attention`，这是待标定的抽象注意假设，并非模拟了独立头部视线或真实眼动。
好奇的直接输入和新奇度衰减仍仅使用原身体FOV，所有好奇参数不变。

首轮十四人CPU实验 `cpu_14_01` 未通过：13号实际核心占位9.725秒后丢失目标，14号过早观察但未玩闹，
没有SCARED覆盖。原配置、轨迹与失败报告保留；后续调整robot_2入场位置/时间，并将玩闹前向目标净距从1.5改为1.8米，
用于形成更稳定的前方占位意图，非实际净距门槛。

双人配置的单角色C++核心切片 `cpu_playful_02` 已通过：10秒实际前方占位、主动侧让和任务恢复；
这是规定机器人运动输入的核心验证，不能代替双人Nav2/Isaac联合运行。


第三轮 `cpu_14_03` 通过144秒闭环核心验证：全部五种瞬时模式、四名心理免疫者始终零心理量、
13号10秒占位并回归，14号8.025秒占位后因预测风险升高开始侧让，随后侧让超时退出，69秒时恢复原任务。
14号本轮没有SCARED：主动侧让解除预测碰撞后仍保持较低恐惧，不能为了展示标签而强行恐惧。
普通行人自然出现SCARED。第二轮的7/13号人体重叠已通过将7号路线移至场地左上方解决，
第三轮人际最小净距0.336米。人机净距只报告，不作为通过条件。

有限注意和运动恐惧默认关闭，旧六人/八人配置保持原样；新模型版本为2.1，仍注册为 `sis_cf_v2`。
实验覆盖、时间、路线及配置哈希汇总于 `docs/expressive_experiment_registry_20261105.yaml`，
运行清单会复制该元数据和参数台账。实际验证还要求13号至少8秒真实前向占位、14号真实前向占位及互动终止/任务恢复，
并检查身体朝向、显示误差、人体重叠和健康状态；不会只凭模式标签通过。


## 实际联合验证结果

运行源码为 `6092b25`，两轮 `source_manifest.json` 的 `source_dirty=false`。十四人场景在种子11下完成134秒机器人刺激、约136.4秒可观测行人演示（269.7秒验收墙钟）；
自动序列正常结束，验收没有失败项。实际Isaac角色中，13号前向占位10.00秒、14号9.95秒，
两人分别停稳对准目标至少1.55、1.25秒；13号完成侧让，14号侧让超时后记录 `yield_timeout` 并恢复任务。
普通1号出现SCARED，恐惧峰值0.664；SCARED期间按实际位置与速度计算，1.5秒内净位移约1.45米，
31个采样的远离目标机器人速度投影均为正值。此指标仅描述反应，不构成导航算法的因果比较。
9～12号始终REGULAR、心理量为零。五种瞬时模式都出现；可视化的第六类IMPASSIVE对应两种不响应类型。
实际人际最小净距0.459米，最大显示误差0.042米，速度与加速度限值未超；人机最小净距0.276米仅记录。

用户指定的双人Nav2专项完成约283.6秒仿真、约297.8秒验收墙钟，13/14号真实前向占位分别10.05/10.00秒，
均完成主动侧让与原任务恢复。最大显示误差0.067米；人机最小净距0.272米仅记录。
两轮 `observations.csv`、`events.csv` 与 `manifest.json` 的格式校验通过，分别导出125982/145与45534/35条观测/事件。
详见 `evidence/expressive_psychology_20261105/` 的验收、数据导出和原始数据索引；CPU前两轮失败记录保留。

这两轮是固定配置和单种子展示，尚未通过多种子统计、30分钟耐久或真实行人参数拟合；
不能据此估计儿童挡路概率、真实心理值或未知导航算法的安全性。`yield_timeout` 是一次有记录的互动终止，
而非“完成侧让”；行人在此之后恢复了原任务。当前展示满足行为覆盖与实际动作检查，保留该失败原因供下一轮交互策略研究。
