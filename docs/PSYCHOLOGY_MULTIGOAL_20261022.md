## 行走路线

原心理路线虽然已配置四点，但只有2米×1米的小范围矩形，视觉上不易辨认转折。
本次沿用普通多目标场景的`loop`和`ping_pong`编译机制，把横向活动跨度扩展为4.5米，
采用明显的四点环线或折线；每人有四个不同目标，折返编译为六项循环队列。
1/2号环线位于各自起点下方，为中部心理停留区留出空间；这是实际碰撞复查后的布局修正。
原普通多目标场景的交叉坐标没有直接套入心理场景，以保留原心理互动区域。

## 动态心理与启动

继续使用双通道SIS模型、原心理参数、两台机器人起点与三轮Nav2任务。
机器人刺激、邻人传播、好奇/恐惧/恢复均由原闭环计算；临时心理行为仍暂停原目标队列，
结束后从实际位置返回原任务。新增行人具有同一套心理模型，实际激活取决于其观测历史。
这次修改不保证每人每次都进入恐惧模式，也不通过脚本强制心理值。

在项目根目录执行，自动展示机器人靠近、穿行、返回及行人心理变化：

```bash
./scripts/run_multirobot.sh config/scenarios/two_robots_multi_sfm_8_multigoal_psychology_nav2.yaml auto_demo:=true
```

去掉`auto_demo:=true`则仅启动场景，机器人目标人工发送。
八人场景使用独立的`two_robots_multi_sfm_8_multigoal_psychology_nav2.yaml`，
引用`multi_regular_8_psychology_multigoal.yaml`。原六人场景文件已按保护标签恢复，
继续引用`multi_regular_6_psychology.yaml`。本次文件名分离不改变已验证的八人布局。
原增强传播场景仍使用旧六人配置；普通无心理多目标场景不变。
本次只改配置，不需重新编译现有已构建的工作区；首次部署仍按原构建文档操作。
