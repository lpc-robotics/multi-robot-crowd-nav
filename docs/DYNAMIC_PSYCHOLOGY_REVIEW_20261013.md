## 结论与范围

双通道SIS型激活、机器人直接刺激、局部心理传播、行为转换与运动反馈组成动态闭环。
其数学更新与接口分层可以继续使用。复查发现的问题集中在行为结束后的运动衔接、
局部观测连续性，以及测试/诊断的完整性；因此重构这些部分并重新构建overlay。
模型参数仍是工程假设，未进行真人标定；场景验收不能解释为任意布局的无碰撞保证。

## 复查保留的设计

- **心理量语义**：c/f属于[0,1]的可共存激活量；不要求和为1，不把行为枚举当作感染舱室。
- **传播与知识分离**：连续外显线索经过有向FOV/距离图传播；不携带威胁机器人身份和坐标。
  邻人运动记忆不生成传播边，隐藏机器人实时位置不参与认知方向。
- **数值约束**：使用全员步前状态和冻结系数指数更新；非负输入下更新是原值与局部平衡值
  的凸组合。整体耦合仍为一阶近似，已设置步长细化测试。
- **默认可恢复性**：行权重和≤1、表达系数≤1、默认beta<mu，为无外部刺激时的衰减提供保守条件。
  增强配置用于接力实验，不能沿用默认恢复保证。
- **单一动力学权威**：心理仅提出期望速度；C++核心保留所有原物理力项并积分一次。
  零期望速度不等于零实际速度；限速与目标速度分离。
- **普通基线**：原v1接口、旧场景和原多目标队列保留；无心理干预的REGULAR走原数值路径。
  旧静态核心与新v1的24,000步逐字段比较记录仍保留，核心此轮未改变。
- **事务边界**：心理状态、邻人记忆和回归标记属于候选状态，响应校验及快照恢复成功后
  才提交。迟到、超时、显示故障或时钟回退不得继续推进心理。

## 验证与使用

构建：7个overlay包；离线：116项Python、29项C++，另有环境重复加载、配置、vendor和underlay保护检查。
真实ROS测试与实际Isaac结果以[证据清单](../evidence/dynamic_psychology_20261012/README.md)
及其`acceptance.json`为准，避免把CPU结果当作实际角色验收。
最终实际双机六人已完成1800.050秒墙钟（957.425秒仿真），最小人机/人际净距
0.290389/0.386764米，显示误差最大0.037520米，零失败；三轮六个Nav2目标全部成功。
验收资源配置及CPU亲和性记录在证据run_profile.json，模型及物理保护阈值未放宽。

原Nav2日志的重放使用实际`last_seen_ns`插值；最长7.225秒无观测区间是直线估计。
重放只作为可复现回归输入，不替代完整真值里程计与实际Nav2运行。

人工入口仍保持一条命令：

```bash
./scripts/run_multirobot.sh config/scenarios/two_robots_multi_sfm_6_multigoal_psychology_nav2.yaml
```

自动有限轮机器人任务追加`auto_demo:=true`。完整参数、验收边界和恢复方式见
[模型开发文档](DYNAMIC_PSYCHOLOGY.md)与[command.txt](../command.txt)。
