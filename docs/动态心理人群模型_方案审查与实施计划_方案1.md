# 动态心理人群模型：方案审查与实施计划

日期：2026-10-12  
项目：lpc-robotics/multi-robot-crowd-nav  
核对的 main：`02dfc6d4ca50984a57cdf6f36ce75e0bbfc957db`  
性质：设计审查与开发计划；尚未实施代码改造或进行新的 Isaac/GPU 验收。

## 1. 决策结论

采用附件《动态行为设计.md》的“连续双心理通道 + 带滞回的行为选择 + 单一运动核心”作为当前主实现，保留此前方案中的事务提交、局部感知、多机器人目标选择、任务恢复和消融设计。

模型名称建议为：**带机器人外部刺激的双通道 SIS 型心理激活—行为切换人群模型**。

这里的“外部”是相对于心理子系统而言；放入完整导航闭环后，机器人动作受人群反馈影响，刺激并非独立于系统。

此前推荐的互斥三态随机模型仍可作为以后比较的另一模型，不与当前连续激活量混用。此次选择依据是研究目标：允许“有兴趣但害怕，所以暂停接近”，并希望研究缓慢心理变化与可解释的行为切换。该选择不等于证明连续方案更符合真实人类心理。

## 2. 两份设计一致在哪里、不同在哪里

| 项目 | 此前三态随机方案 | 附件连续双通道方案 | 本次决定 |
|---|---|---|---|
| 总体结构 | 刺激—传播—行为—运动反馈 | 相同，并更明确区分线索与内部心理 | 一致，保留 |
| 心理状态 | 单人处于 N/F/C 中一个主导状态 | c、f 两个连续激活量可同时存在 | 主实现选连续方案 |
| 数学约束 | 概率近似满足 pN+pF+pC=1 | c、f 分别属于 [0,1]，和可大于 1 | 不能混用两种语义 |
| 切换机制 | 转移率驱动随机跳变 | 连续心理经过阈值、滞回和目标条件选择动作 | 主实现使用确定性选择器 |
| 好奇与恐惧关系 | 基线互斥，可增加 C→F 转移 | 可共存，可选恐惧抑制好奇 | 抑制项设为独立开关 |
| 模型优势 | 随机感染状态清楚，适合传播统计和随机过程分析 | 易表达积累、混合心理与行为保持，便于重复对照 | 适合当前工程目标 |
| 主要代价 | 个体心理被简化为互斥状态；小人群单次波动明显 | 多出行为阈值与表达假设，不能称为精确感染概率 | 明确假设并分阶段标定 |

“SIS + SFM”已有先例，例如 Cao 等的 P-SIS 情绪传播与社会力耦合工作；但它不能作为本方案好奇/恐惧方程、机器人刺激或抑制项已被实证验证的依据。附件引用指向真实相关文献，但并未提供其双通道方程的直接文献推导。

附件包含导出残留的 Mermaid CSS 文本；其不是模型内容，本计划不沿用。

## 3. 模型定义及数学检查

### 3.1 状态与语义

每个行人保存：

- 运动：位置 p、速度 v、朝向 yaw。
- 心理：好奇激活 c∈[0,1]、恐惧/警觉激活 f∈[0,1]。
- 特征：激活敏感度、传播易感性、恢复速率；首版先用统一参数。
- 行为：regular、curious、scared；轻度警戒暂作为 regular 的内部参数变化。
- 信息：已观察机器人、兴趣目标、威胁目标及观测时间。
- 历史：逐机器人熟悉度、行为进入时间、原任务进度。

c、f 是现象学激活量，不是互斥状态概率，不要求 c+f≤1。心理可以共存，但每步执行一种主导行为意图。

### 3.2 建议主方程

令 q∈{C,F}，所有参数非负，输入及邻接权重有限：

\[
\lambda_i^q=\alpha_i^q s_i^q+\beta_i^q\sum_{j\ne i}w_{ij}^q y_j^q,
\]

\[
\dot c_i=(1-c_i)\lambda_i^C-\mu_i^C c_i-\kappa_i f_i c_i,
\qquad
\dot f_i=(1-f_i)\lambda_i^F-\mu_i^F f_i.
\]

s、w、y、c、f 均无量纲；α、β、μ、κ 的单位为 s⁻¹。y 是外显线索代理，首版明确设为 yC=ηC c、yF=ηF f，η∈[0,1]。它表示心理按一定比例外显的理想化假设，不是实际相机已经估计出情绪。

数学边界检查：

- c=0 时，ċ=λC≥0；c=1 时，ċ=−μC−κf≤0。
- f=0 时，ḟ=λF≥0；f=1 时，ḟ=−μF≤0。

因此，在输入非负、有限且满足适当的解存在条件时，连续系统的 [0,1]² 区域正向不变。这说明状态边界自洽，不代表心理学有效性，也不保证任意数值积分步长均不越界。

**修正与取舍：**

1. κf c 是待验证的单向抑制假设；首先设 κ=0，跑通后再启用并比较。恐惧优先决定行为本身已能阻止危险接近。
2. 恢复项应保留，但刺激撤除不必导致全体立即恢复。传播可能维持激活，需要在低传播增益的专门场景验证恢复。
3. 明确“恐惧不等于高速逃跑”。行为由目标、风险与可执行方向共同决定。
4. 不再同时维护一个用于随机抽样 N/F/C 的状态过程，避免连续激活与随机感染状态互相矛盾。

### 3.3 数值更新与同步

所有行人从共同步前快照计算 λ 和外显线索，再一起更新；不能按行人编号原地更新并立刻影响后面的行人。

对于每个冻结系数子步，可把单通道写为 q̇=A−Bq：

\[
q^{n+1}=\frac{A}{B}+\left(q^n-\frac{A}{B}\right)e^{-B\Delta t},\quad B>0.
\]

- 恐惧：A=λF，B=λF+μF。
- 好奇：A=λC，B=λC+μC+κ fⁿ。
- B=0 时 A=0，保持 q 不变。

此步在系数冻结条件下是精确更新，并保区间；对整个耦合系统仍是数值近似。用 dt 与 dt/2 检查代表性场景的状态和切换时间，不以强行裁剪掩盖积分错误。

当直接刺激恒定、传播关闭、κ=0 时，稳态 q*=λ/(λ+μ)。选阈值前需检查 q* 是否超过进入阈值，否则行为永远无法触发。该关系可用于标定；不要同时盲调刺激强度、恢复率和阈值。

## 4. 刺激、传播及信息边界

### 4.1 机器人直接刺激

第一版只使用可观察的几何量：净距、相对接近趋势、视野；可加入有限预测窗内的最近接近距离与对应时间。只有处于预测窗内且预计间距不足，才认定相对运动有风险。不能以“距离/机器人速度”代替通用 TTC，也不能让远处高速驶离的机器人必然造成高恐惧。

- 恐惧：近距与接近风险组成有界威胁评分。
- 好奇：可见性 × 新颖性 × 低威胁门控；缓慢移动只是可选线索，不是好奇的充分条件。
- 多机器人刺激采用明确的有界聚合，例如 s=1−exp(−Σk eik)，eik≥0；记录各机器人贡献，不能仅使用 robot_1。

首版场景可无遮挡，明确不宣称已实现遮挡感知。心理感知不应把当前位置、已知目标列表等仿真信息无条件视为个体已知。

### 4.2 熟悉度

为好奇目标保存逐机器人熟悉度 hik∈[0,1]；一个简单版本是 ḣik=ν Vik(1−hik)，新颖性使用 1−hik。短期离开视野不清零；episode reset 时统一重置。遗忘机制和目标关联不确定性留待后续。

ν 是情景建模参数，不是实测人类时间常数。首版只要避免同一机器人短暂消失又回来就被当作全新刺激。

### 4.3 动态人际网络

\[
w_{ij}(t)=K(d_{ij}(t))V_{i\leftarrow j}(t),\qquad w_{ii}=0.
\]

首版两个通道共用同一几何网络，降低自由度。K 用有限支撑、随距离平滑衰减的核；V 用有向视野权重。group 和关系权重默认关闭。

每步从位置、朝向重新计算网络。make_context 中存在“全对邻居列表”只表示输入可用，尚不等于已存在有向传播权重。

先使用未按邻居数归一化的加权和，并记录 Σj wij；这保留接触数量的影响。若后续改用平均输入，应作为独立模型配置，不能静默更换而继续沿用 β 的解释。需要饱和传播时，也应显式增加饱和函数。

### 4.4 不允许全知逃离

心理激活与威胁定位分开保存。B 看见 A 的异常反应，可以警觉升高，但不自动继承全场机器人真值。

- 有可信威胁位置：可形成定向避让意图。
- 无威胁方向：保持 regular 中的谨慎运动、减速或观察；不精确逃离未观察机器人。
- 有好奇而无兴趣对象：观察，不凭空接近。
- 第一版允许短时观测记忆，明确过期时间与失效处理，不假设已经完成视觉跟踪。

## 5. 行为选择与连续运动

### 5.1 规则优先级

1. 即时几何避碰始终有效，高风险立即中止接近。该保护本身不强制把 f 设为 1。
2. f≥θF_on 且存在可执行的威胁方向，进入 scared；低于 θF_off 才允许退出，θF_off<θF_on。
3. f 高但目标不可定位，转为 regular 的警戒参数；保留高 f。
4. c≥θC_on、f 足够低、有可感知兴趣对象且接近可行，进入 curious。
5. curious 在 c≤θC_off、威胁升高、目标失效或接近不可行时退出。
6. 其他情况执行 regular；scared 退出后重新评价 c，不自动清空好奇。

使用进入/退出滞回与目标保持避免抖动。若增加最短行为保持时间，必须允许高风险中断；首版不必添加大量计时器。

### 5.2 意图与运动职责

| 模式 | 行为层输出 | 运动核心职责 |
|---|---|---|
| regular | 原任务对应的期望速度/方向，轻度警戒可有速度调整 | 继续任务、统一避障和积分 |
| curious | 指向可感知兴趣机器人的临近期望速度，在停止距离外收敛到停留 | 检查运动限制，避免接近与排斥冲突 |
| scared | 基于已感知威胁生成远离/绕行期望方向，速度有界 | 与墙体、人际、其他机器人作用合成并积分 |

不能以负社会力倍率模拟好奇吸引。不能关闭独立近距离项。保留当前物理包络，在可行距离上先实现观察停留；如需改变物理参数，应单独校准，不由心理状态动态修改。

### 5.3 任务与多机器人目标

- curious 保存一个兴趣目标 ID，采用评分差值/保持机制避免每步换目标。
- scared 与即时风险判断考虑所有已感知机器人。
- 原任务队列是持久任务；临时行为不能覆盖它，也不能因抵达临时目标而弹出原路点。
- 特殊行为中暂停原任务路点推进；恢复 regular 后重新按当前实际位置判断原路点。该选择应固定记录，避免不同模式采用隐含不同规则。
- 全场仅一个运动核心推进每个行人一次。HuNav 的现成动作若内部调用运动更新，应提取其意图逻辑，不能与当前积分器直接串联调用。

## 7. 可执行开发阶段

### P0：保护基线与明确边界

- 在部署主机检查实际 Git HEAD、未提交修改、当前启动入口；与本计划核对提交不同则先列差异，不盲目覆盖。
- 保存干净提交/备份标签；未提交内容单独备份。新开同级目录及独立分支，例如 feature/psychology-behavior-v1，使用独立 build/install/log。
- 稳定 arena5_ws、旧 release、旧证据只读；不为通过验证刷新 underlay 基线。
- 保留 noop 与原场景，确认现有双机六人链路可启动。最新 FOV 源码与历史 GPU 证据不能自动视作同一版本验收。

交付：基线说明、回退入口、新目录。门槛：旧流程可恢复。

### P1：先打通行为执行，心理仍关闭

- 增加 v2 意图接口及统一行为执行，补任务恢复。
- 使用独立诊断模式手动指定 regular/curious/scared，目标为一台明确可见机器人。
- 检查接近、可行距离停留、远离和恢复任务；避免调用会重复积分的原 HuNav 动作。
- 日志醒目标记 forced_behavior=true。正式模型默认关闭，不将人工切换结果当作心理涌现。

交付：一机器人一行人的三个行为执行演示。门槛：动作语义正确、目标不丢失、无重复积分。

### P2：单人双通道心理与行为闭环

- 接通刺激、yaw、短时观测记忆、熟悉度和 c/f 更新。
- βC=βF=0、κ=0。机器人脚本依次提供观察机会、接近风险与撤离；行人模式由模型产生。
- 先固定恢复率，再调直接刺激，最后设置可达到的进入/退出阈值。
- 不要求所有参数和人物都出现固定“普通→好奇→恐惧→普通”序列。用不同刺激/敏感度出现不同响应。

交付：c/f、刺激与模式时间曲线，以及实际轨迹。门槛：模式与状态/目标条件相符，心理共存、风险可中断、任务可恢复。

### P3：两个行人的间接警戒与传播

- 增加 A/B 两人；首先只开启 βF，βC=0，κ=0。
- 第一组先在离线模型中固定几何，明确令 B 的机器人直接输入为零，隔离传播机制；报告这是受控机制实验。
- Isaac 场景再用经核验的视野/布局限制 B 的直接刺激，并逐时记录其刺激。若 B 后来确实看见机器人，不能继续声称它只有间接输入。
- 对照关闭 βF。B 在无方向信息时只能警戒，不全知逃离；记录 B 获得目标信息的时刻。

交付：直接刺激与传播分项、传播网络、B 响应对照。门槛：能明确归因，且无隐藏直接刺激。

### P4：双机六人最小人群

- 重排原六条往返线路为有局部持续接触的交叉/同向混合场景；不增加 group，不同时扩人数。
- 对齐机器人速度上限及任务配置。先以已有低速配置为参照；更高速度另做核验，不沿用旧结论。
- 两台机器人分别进入视野，验证逐机器人刺激、兴趣目标保持和多目标风险判断。
- 比较同时通行与错峰通行。机器人可用外部脚本控制，但行人行为仍由模型产生。

交付：可重复的双机六人闭环场景、配置与结果。门槛：两台机器人都能影响模型，改变时序可产生可解释差异；没有差异也如实报告并检查机制强度。

### P5：冻结模型版本，再转向导航算法

- 保留 noop、有刺激无传播、完整耦合三个基线。
- 分别开启 βC 与 κ，检查是否增加解释价值；没有必要就保持关闭。
- 固定一版场景、参数、接口和评估指标；先比较独立导航与简单优先级/错峰协调。
- 再开展心理反馈预测、MPC/DRL/diffusion。实机可观测性作为下一阶段；不得把仿真内部心理真值直接当作部署输入。

当前完成目标是 P4，不是先完成六行为、复杂社交群组、大规模场方程或训练系统。

## 8. 最小参数与验收设计

### 8.1 可运行的调试起点（非实证标定）

| 参数 | 演示初值 | 单位/解释 |
|---|---:|---|
| αC / αF | 0.4 / 0.8 | s⁻¹；直接输入 s∈[0,1] |
| μC / μF | 0.15 / 0.25 | s⁻¹；无输入时恢复时间尺度约 6.7 / 4 s |
| βC / βF | 0 / 0 | P2 关闭；P3 将 βF 从 0.1 s⁻¹ 起调 |
| κ | 0 | 先不抑制内部好奇，只在行为层进行风险优先 |
| θC_on / θC_off | 0.55 / 0.30 | 无量纲 |
| θF_on / θF_off | 0.60 / 0.35 | 无量纲；退出 scared 不等于马上进入 curious |
| curious 恐惧允许上限 | 0.25 | f 低于该值且风险门控通过才允许接近 |
| ηC / ηF | 1 / 1 | 外显代理的理想化调试值 |
| 熟悉度增长 ν | 0.05 | s⁻¹；仅在可见时累积 |

这些数值用于工程联调；距离阈值、停止距离、风险评分窗应根据机器人/行人半径与既有近距离力扫描确定，禁止把中心距离和表面净距混用。

固定直接输入为 1、无熟悉度衰减和传播的单人检查中，c*=0.727、f*=0.762，均可超过上述进入阈值。正式好奇输入受熟悉度与风险门控影响，需检查实际曲线，不保证所有情景都触发。

### 8.2 只做针对具体风险的必要检查

1. 边界与时间：c/f 不越界；零输入按预期恢复；dt 减半结果合理接近。
2. 事务：计算失败/迟到时，模式、目标、熟悉度和任务进度均不提前提交。
3. 行为：目标恢复、停留距离、高风险中断、目标失效处理；每步只积分一次。
4. 因果：受控零直接输入下，关闭传播后 B 不产生传播导致的响应。
5. 感知：机器人在背后/视野外不能提供视觉激活；但近距离运动排斥仍存在。使用记忆时明确追踪其贡献。
6. 双机：移除任一机器人或改变其时序，检查对应刺激/目标/轨迹是否按定义变化。

恢复专门场景使用传播较弱且直接输入最终消失的参数。若在线性表达 yF=ηF f 的固定网络上分析小扰动，可检查 diag(βF) W diag(ηF)−diag(μF) 的谱；它只是简化条件下的分析，不自动证明时变人群全局稳定。

### 8.3 指标与归因

- 模型状态：c/f 峰值、积分、模式占比、切换次数、恢复时间。
- 机制：逐机器人直接刺激、邻居传播输入、权重行和、目标来源/年龄。
- 运动：实际净距、速度、绕行、行人任务延误、机器人任务完成。
- 实验：模型/代码版本、参数、场景、随机种子、仿真时间。

核心消融是无心理、仅直接刺激、直接刺激+传播。κ 与 βC 后续各自独立比较；不把它们同时打开后就声称知道改善来自哪一项。

若测试“心理开启但行为反馈关闭”，外显 y=ηq 是否继续开放必须显式说明；否则心理线索可能随着行为开关一起变化，混淆对照。

## 9. 可以交给 Codex 的实施任务

请在独立目录和分支实施本计划 P0–P4，按阶段完成并保留回退点。先检查实际 HEAD 与本计划核对提交的差异；不修改稳定 underlay 或旧 release，不覆盖历史证据。

主模型采用连续 c/f 激活量，不采用互斥 N/F/C 抽样。先打通行为意图和任务恢复，再接入直接刺激与心理 ODE，然后接恐惧传播，最后验证双机六人。保留 noop 和原服务兼容路径；新增接口有版本，不混用不同 IDL 的进程。

所有行人使用共同步前状态计算。心理、模式、目标、观测历史与任务进度作为一个候选事务提交。行为层只输出意图，唯一运动核心完成一次积分。curious 必须显式生成接近意图与可行停留距离；scared 只使用已观察/有效记忆中的威胁方向。未知威胁方向时执行警戒而非全知逃离。

开发中只补本计划列出的关键验证，不为本轮引入 group、六行为全集、大规模人群、训练框架或完整场论。交付改动说明、配置与启动命令、每阶段证据、已知限制、回退命令。若未实际运行 Isaac/GPU，明确标为未验收，不以单元测试替代实际轨迹证据。
