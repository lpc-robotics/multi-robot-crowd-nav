# SCARED 专项：外部机器人风险刺激实验

日期：2026-11-03。开发前源码86db90a，保护标签`backup-scared-stimulus-20261103`，
开发分支`feature/scared-stimulus-20261103`。用户已有的2026-10-26完整备份继续保留，
本标签保护该快照之后的V2和人群可视化源码；源码切换后重新运行`./scripts/build.sh`。

## 实验目的与模型边界

测试导航输出能否通过实际机器人运动，引起风险感知、恐惧积累、SCARED退让和任务恢复。
脚本只生成机器人速度指令，不写行人的c/f/s、行为模式、身体朝向或任务队列。
未来算法也通过同一外部速度接口接入；需另跑相同场景并保存完整轨迹，比较实际暴露。

```mermaid
flowchart LR
    A[几何刺激或未来导航算法] --> B[cmd_vel_external]
    B --> C[速度限幅与健康看门狗]
    C --> D[Isaac机器人实际运动]
    D --> E[个人感知与风险计算]
    E --> F[恐惧SIS及人际传播]
    F --> G[SCARED意图]
    G --> H[社会力积分与实际行人运动]
    H --> E
    D --> I[独立几何和反应验收]
    H --> I
```

看门狗负责指令新鲜度、限幅、健康和急停，不具有DWB的代价地图避障功能。

现有模型的风险输入由人机净距、相对接近速度、预测最近净距和预测时域构成。
恐惧SIS达到0.65时可进入SCARED；即时风险达到0.85还有独立紧急覆盖。
日志必须区分`reason=fear`和`reason=emergency_override`，不能只看红色模式标签。
当前不直接描述礼貌规范、声音、机器人造型、加加速度或所有主观不适。
仿真激活不是实测人类恐惧，本实验不证明模型已经过真人数据验证。

首轮原始200°心理视野试验中，行人身体转向避让后机器人离开视野，直接刺激消失；
0.5、0.8、1.0m/s的不同控制参数均未触发SCARED。不能把物理避让自动算作心理恐惧。
因此主展示为**明确配置的持续注意条件**：仅1号行人的心理机器人FOV设为360°，
代表实验中持续注意机器人，避免身体转向立即切断刺激。它不是已测量的人类视野，
没有独立头部朝向动画；物理社会力FOV仍为原来的200°。原心理系数和阈值全部沿用V2。
另提供200°身体朝向版本，保留未触发结果，用于研究感知限制。
当前个人机器人记忆可提供有界位置预测、行为方向和紧急风险判断，但不会持续作为
直接恐惧SIS输入；因此“转身后仍记得机器人”和“继续积累直接恐惧”是两个不同条件。
后续模型改进应把身体运动方向与注意/注视方向分开，并用真实数据辨识注意保持和记忆，
再通过本实验复测。不能把360°实验覆盖直接推广为所有行人的默认能力。

## 场景与刺激

同一开放场地，1台机器人、6名行人。1～4为standard，5为immune_dynamic，6为impassive_static。
1号在(16,10)开始缓慢循环行走，是主要受刺激者；2～4为周围行人，5～6在远处继续行走。
远处两类免疫者不是同暴露配对实验，不能据此单独估计个体类型的因果效果。
基础期望速度分别为0.3/0.4m/s，身体半径0.4m，硬速度1m/s、加速度3m/s²保持原值。

机器人在(7,10)开始，采用有限次外部几何控制，**不启动Nav2/DWB**：

1. 静止准备8秒仿真时间，允许原有惊讶/好奇自然发生。
2. 接近并持续跟随1号位置24秒；不读取行人心理或下一任务目标。
3. 返回起点，最多45秒；停止或转向不重置本阶段截止时间。
4. 原地等待25秒，观察恐惧恢复和原任务继续；随后持续发零速度。

| 条件 | 最高机器人速度 | 目标人机净距 | 接近增益 | 心理条件 |
|---|---:|---:|---:|---|
| intrusive 主压力刺激 | 0.8m/s | 0.35m | 4/s | 仅1号持续注意 |
| considerate 礼让对照 | 0.15m/s | 1.8m | 1/s | 与主压力刺激完全相同 |
| body_fov 感知诊断 | 与intrusive相同 | 与intrusive相同 | 与intrusive相同 | 原200°身体视野 |

目标净距是控制器的期望值，实际值由机器人运动和行人响应共同决定，不能写成实测最小净距。
0.8m/s需要新场景中的`allow_high_speed_external: true`显式启用，平台上限仍为1m/s；
普通multi_sfm场景仍限制0.5m/s，Nav2不能利用此开关提速。
原command_guard、健康心跳、观测超时、仿真时间跨度和急停保留。
刺激程序发现任一行人净距低于0.18m即中止，不以实际碰撞作为成功刺激。
实际验收仍要求净距≥0.10m、人际/墙体无重叠、显示误差≤0.25m。

## 启动与未来算法

主展示：

```bash
cd /home/lpc/workspace/arena5_multi_ws
./scripts/run_multirobot.sh config/scenarios/one_robot_multi_sfm_6_scared_intrusive_external.yaml auto_demo:=true crowd_viz:=true isaac_overlay:=true viz_focus_id:=1
```

每次结束上一轮后再启动礼让对照或感知诊断；不要同时向同一机器人发两组控制指令。
对照分别替换场景名为`one_robot_multi_sfm_6_scared_considerate_external.yaml`、
`one_robot_multi_sfm_6_scared_body_fov_external.yaml`。
去掉`auto_demo:=true`即可接入自己的导航算法，向`/robot_1/cmd_vel_external`
发布`geometry_msgs/Twist`，由既有command_guard输出到机器人。
此时几何刺激程序不会启动，算法须自行提供规划/控制。可继续使用地图、机器人里程计和激光；
主刺激控制器使用Isaac实际行人位置作为实验生成条件，不把它当作未来算法必须拥有的输入。

`/multirobot/fear_stimulus/status`记录几何阶段、时刻、实际输入采样时刻、速度指令及采样净距；
运行目录中`fear_stimulus.json`记录有限协议执行结果，独立心理/几何验收报告另行保存。
`source_manifest.json`保存有效个体配置、实验台账和刺激配置的确切哈希。

## 参数、验证与解释

心理参数标记仍见`parameter_registry_v2.yaml`；实验设置及1号360°FOV覆盖另见
`scared_stimulus_experiment_registry.yaml`。协议时长、刺激距离和控制增益属于实验工程设置，
不进入心理拟合候选；感知覆盖和基础期望速度仍是未拟合假设，不能与硬上限混淆。

CPU闭环入口为`scripts/validate_scared_stimulus_cpu.py`，实际Isaac验证由
`scripts/validate_psychology_v2_experiment.py`自动选择新的SCARED探针。
探针保留原V2几何、同步、事务和运动门槛，主展示还要求：恐惧量≥0.65、
`reason=fear`累计≥0.5s、实际向远离机器人方向运动≥0.5s且累积位移≥0.1m，
以及退出SCARED后任务重新允许推进、最终恐惧回落至0.35以下。礼让对照不应出现1号SCARED。
200°诊断可能不满足主展示的SCARED门槛，应保留失败或未触发结果，不调低门槛取得通过。

最终布局的CPU闭环：持续注意条件下1号fear峰值约0.656、`reason=fear`约15.5s，
最小人机净距约0.402m；主压力组和礼让组另在协议结束后继续120秒仿真，几何检查通过。
实际压力组已在源码5a82112下通过120.067秒墙钟、119.125秒仿真验证：
1号fear峰值0.65465、`reason=fear`持续17.05秒，实际向外运动17.05秒、
累积径向投影位移13.707m；退出SCARED后任务允许推进3272个采样，临时目标队列暂停检查5474次。
最小人机净距0.3784m、人际净距0.6982m、显示误差0.0392m，核心速度≤0.933m/s，
加速度≤3m/s²。

两组有效个体参数、模型配置、源码和人群路线摘要完全一致。速度、接近增益和期望净距
同时变化，当前比较不单独估计其中某一项的效果。最终重建、187项Python和32项C++检查通过。
完整导出保留实际/核心/机器人观测与单独的潜变量；全时间窗对比图包含未触发和恢复阶段。
图和元数据见[最终对比图](../evidence/scared_stimulus_20261103/comparison_figures_final/fear_comparison.png)，
可用`scripts/plot_scared_stimulus.py`根据标准导出目录重画。

两次实际失败均保留：首轮启动前空人群心跳被错误拒绝，并发现原新增背景路线相交；
第二轮详细状态约1Hz，错误地使用0.6s超时造成刺激提前结束。修正启动等待、背景路线及
详细状态2s接口契约后通过，Bool健康心跳0.6s及原几何/同步/运动门槛保持不变。
实际实验、对照、失败迭代与最终结论记录在`evidence/scared_stimulus_20261103/`。
两种导航输出的一次配对差异不能证明真人不适或统计因果；相同种子也不保证异步系统逐帧重放。

## 2026-11-05 验收口径补充
